# Новые Горизонты — Astro starter

## Запуск на Mac
1. Установите Node.js LTS: https://nodejs.org/
2. Откройте Terminal и перейдите в папку проекта: `cd путь/к/novye-gorizonty-astro-site`
3. Выполните `npm install`
4. Выполните `npm run dev` и откройте адрес, который покажет Terminal.
5. Для проверки production-сборки: `npm run build`.

## Что включено
- Astro + Tailwind CSS v4 (через Vite plugin)
- тёмная адаптивная главная, шаблон статьи, рубрики
- экспортированные записи и страницы WordPress
- файлы из `wp-content/uploads`
- CSV-ведомости миграции и медиа

## Важно перед публикацией
- Контент WordPress сохранён как HTML внутри Markdown; проверьте рендеринг каждого материала.
- Классификацию страниц/рубрик, ссылки внутри статей, изображения и метаданные нужно проверить вручную.
- Динамический маршрут использует исходный URL из экспорта, но перед переключением домена нужен полный аудит старых URL и 301-редиректов.
- CMS пока не подключена.
- Старый WordPress не удалять до проверки нового сайта и резервной копии.
